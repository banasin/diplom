# Спецификация реализации: Часть 3 (спектр мишеней и кросс-реактивность)

**Дата:** 2026-08-15
**Проект:** Предсказание аффинности аптамер–мишень. Часть 3 — переход от
аффинности к одной мишени к предсказанию профиля аффинности по набору мишеней;
анализ кросс-реактивности как эмерджентного свойства парной модели.
**Основа:** Части 1–2 завершены (парные модели аффинности: two-tower, XGBoost;
ESM-2 эмбеддинги белков; честный кластерный сплит). Часть 3 переиспользует их.

## Контекст и постановка

Кросс-реактивность в данных **разрежена**: из 1972 аптамеров лишь 79 связывают
≥2 мишеней (50 — ≥2 белков), 96% измерены против одной мишени. Обучать
supervised-модель профиля невозможно (профиль почти везде неизвестен). Поэтому
кросс-реактивность рассматривается как **эмерджентное свойство парной модели**:
обученная на train модель аффинности предсказывает матрицу аптамер×белок, из
которой извлекаются профили и оценки кросс-реактивности; валидация — на
отложенных аптамерах против известных мишеней.

## Гипотезы

- **H5 (retrieval):** парная модель ранжирует истинные мишени аптамера выше
  случайного — для отложенного аптамера его известные мишени стоят высоко в
  предсказанном профиле по панели.
- **H6 (эмерджентная кросс-реактивность):** известные мульти-таргетные аптамеры
  (≥2 известных белка) получают более высокую модельную оценку кросс-реактивности
  из профиля, чем специфичные (1 мишень) — кросс-реактивность возникает из модели,
  а не задаётся явно.

## Зафиксированные решения

| Вопрос | Решение |
|---|---|
| Постановка | Эмерджентная кросс-реактивность от парной модели (не supervised-профиль) |
| Базовые модели | XGBoost + two-tower (сравнение: свойство модели, а не артефакт) |
| Панель мишеней | Только белки (~414 уникальных с ESM-2) |
| Оговорённые значения | Оставляем (максимум кросс-реактивных случаев) |
| Сплит | Кластерный по аптамеру (Часть 1): обучение на train, профили для test |
| H6 при малом n | Оценка на test-аптамерах со статистической оговоркой + описательное распределение по всем аптамерам |
| Компьют | Windows, RTX 4070 (CUDA) |

## Модульная структура

Переиспускаемое без изменений: `src/features/aptamer.py`, `src/features/protein.py`
(ESM-2, кэш), `src/features/protein_seqs.py`, `src/data/cluster.py`,
`src/data/split.py`, `src/models/baseline.py`, `src/models/twotower.py`,
`src/evaluation/metrics.py`, `src/config.py`.

### 1. `src/data/spectrum.py` — панель и известные мишени

- `build_target_panel(pairs, protein_emb) -> list[str]` — упорядоченный список
  уникальных белков-мишеней (target_key), у которых есть ESM-2 эмбеддинг; это
  панель P для профилей.
- `known_targets_by_aptamer(pairs) -> dict[str, set[str]]` — для каждого аптамера
  множество его известных белков-мишеней (из измеренных пар).
- Вход — белковые пары (медиана log-Kd, оговорённые оставлены), с метками сплита
  из `make_splits`.

### 2. `src/evaluation/ranking.py` — ранжирующие метрики

- `ranking_metrics(scores, is_positive, ks=(1,5,10)) -> dict` — по вектору
  предсказанных аффинностей (чем сильнее связывание, тем выше ранг) и булеву
  вектору истинных мишеней: `roc_auc`, `average_precision`, `precision@k` для
  каждого k, `best_true_rank` (ранг лучшей истинной мишени). На sklearn.
- Замечание по знаку: сильнее связывание = меньше log-Kd; ранжируем по
  возрастанию log-Kd (или по `-log_Kd` как «сила»). Функция принимает уже
  ориентированный «скор силы связывания» (больше = сильнее).

### 3. `src/cross_reactivity.py` — профили и оценки

- `predict_profiles(model_predict_fn, test_aptamers, panel, aptamer_feats,
  panel_emb) -> np.ndarray (N_test, |P|)` — матрица предсказанных log-Kd
  test-аптамер×панель; `model_predict_fn` абстрагирует XGBoost/two-tower.
- `cross_reactivity_score(profile, threshold) -> float` — первичная оценка
  кросс-реактивности аптамера из профиля: **число мишеней панели с предсказанной
  силой связывания выше порога** (predicted-binders count); порог — параметр
  конфига. Дополнительно (вторично) возвращается разброс профиля (std) как
  описательная характеристика.
- `emergence_test(scores_multi, scores_single) -> dict` — сравнение оценок
  кросс-реактивности мульти-таргетных и специфичных аптамеров: U-статистика
  Манна–Уитни, p-value, размер эффекта (rank-biserial). scipy.

### 4. `src/run_part3.py` — оркестратор

- Строит белковые пары → кластерный сплит → панель + известные мишени.
- Обучает XGBoost и two-tower на train-парах (признаки: k-меры аптамера + ESM-2
  белка).
- Для каждой модели: строит профили test-аптамеров по панели; считает
  - **H5:** ranking_metrics по каждому test-аптамеру (у которого ≥1 известная
    мишень в панели), усреднённо + сравнение со случайным бейзлайном;
  - **H6:** cross_reactivity_score по всем test-аптамерам; emergence_test
    (мульти vs специфичные) + описательное распределение.
- Пишет таблицы (`results/metrics/part3_ranking.csv`,
  `results/metrics/part3_crossreact.csv`) и графики (тепловая карта профилей
  примеров мульти-таргетных аптамеров; распределения оценок; ROC-кривые).

### Конфигурация

`configs/part3.yaml`: seed, порог кластеризации, доля теста, k, имя ESM-модели,
гиперпараметры XGBoost и two-tower, порог силы связывания для оценки
кросс-реактивности, список k для precision@k.

## Поток данных

```
dataset_protein.parquet
   └─ build_pairs(keep_qualified) → cluster+split (по аптамеру)
белки: protein_seqs → protein.py (ESM-2, кэш)
   ├─ обучение XGBoost и two-tower на train-парах
   └─ spectrum.py: панель P + известные мишени по аптамеру
       └─ cross_reactivity.py: профили test-аптамер×P
           ├─ ranking.py (H5): ROC-AUC/AP/precision@k/ранг
           └─ emergence_test (H6): мульти vs специфичные
   └─ таблицы + графики
```

## Тестирование

- Юнит-тесты:
  - `build_target_panel`/`known_targets_by_aptamer` на маленькой таблице пар;
  - `ranking_metrics` на известных массивах (идеальное ранжирование → AUC=1,
    ранг лучшей истинной = 1; случайное → AUC≈0.5);
  - `cross_reactivity_score` (профиль с известными значениями → ожидаемое число
    над порогом);
  - `emergence_test` на синтетике (мульти заметно выше → малый p, положительный
    эффект);
  - `predict_profiles` на синтетике с мок-`predict_fn` (форма матрицы, порядок).
- Инвариант честности: профили строятся только для test-аптамеров; их пары не
  участвовали в обучении.
- Детерминизм при фиксированном seed.
