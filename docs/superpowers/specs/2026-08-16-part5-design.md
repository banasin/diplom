# Спецификация реализации: Часть 5 (усиление нейроподхода на задаче спектра)

**Дата:** 2026-08-16
**Проект:** Предсказание аффинности аптамер–мишень. Часть 5 — расширение
(в исходном плане диплома было 4 части): сделать нейросетевой подход
конкурентнее на задаче спектра мишеней, где он проиграл интерпретируемым
MNA/N-граммным моделям (Части 3–4).
**Основа:** Части 1–4 завершены. Часть 5 переиспользует их модули и данные.

## Контекст и мотивация

Прямое сравнение (Часть 4): на задаче спектра интерпретируемые модели дают
per-target IAP ~0.965 (честный held-out 0.67–0.95), а наша нейросеть — per-target
AUC ~0.55 (per-aptamer retrieval ~0.47 ≈ случайное). Диагноз: (а) обучали парную
**регрессию** log-Kd, а мерили **ранжирование** спектра (рассогласование цели);
(б) аптамер кодировался «сырыми» k-мерами (SHAP: вклад ~28%, структура ~2%),
тогда как мишень — мощным ESM-2. Часть 5 проверяет два рычага против этих причин.

## Гипотеза

- **H9:** ранговая цель обучения и/или предобученный нуклеотидный энкодер аптамера
  улучшают предсказание спектра (per-aptamer ROC-AUC и per-target AUC) над baseline
  «k-меры + регрессия» (Часть 1) и сокращают разрыв с интерпретируемыми моделями.

## Зафиксированные решения

| Вопрос | Решение |
|---|---|
| Объём | Абляция 2×2: {регрессия | ранжирование} × {k-меры | Nucleotide Transformer} |
| Энкодер аптамера | Nucleotide Transformer (ESM-подобный, `transformers`), mean-pooling, кэш; старт `InstaDeepAI/nucleotide-transformer-v2-100m-multi-species` |
| Ранговая цель | Попарная BPR/маржинальная потеря с сэмплированием K негативов на позитив |
| Мишень | Белки, ESM-2 650M (кэш из Частей 1–2) |
| Оценка | Задача спектра: per-aptamer ROC-AUC + per-target AUC, честный кластерный сплит; сравнение с OLMPASS IAP |
| Оговорённые значения | Оставляем (как Части 2–4) |
| Негативы | Мишени панели без измеренной пары к аптамеру (приближение, отмечено) |
| Компьют | Windows, RTX 4070 12 ГБ (CUDA) |

## Модульная структура

Переиспускаемое без изменений: `aptamer.py` (k-меры), `protein.py`/`protein_seqs.py`
(ESM-2), `cluster.py`, `split.py`, `data/spectrum.py`, `evaluation/ranking.py`,
`evaluation/per_target.py`, `data/olmpass.py`, `config.py`, `metrics.py`.

### 1. `src/features/aptamer_lm.py` — эмбеддинги Nucleotide Transformer

- `embed_aptamers(seqs:dict[str,str], model_name:str, cache_path:str,
  batch_size:int=8) -> dict[str,np.ndarray]` — mean-pooled эмбеддинг нуклеотидной
  языковой модели (аналог `protein.py`/`molecule.py`); U→T нормализация; кэш `.npz`
  (вне git), атомарная запись; загрузка через `AutoModel`/`AutoTokenizer`
  (при необходимости `trust_remote_code=True`).
- Ключ словаря — последовательность аптамера (нормализованная).

### 2. `src/models/ranking_twotower.py` — two-tower скор + две цели

- `ScoreTwoTower(nn.Module)` — башня аптамера (вход: вектор признаков аптамера,
  k-меры **или** NT-эмбеддинг), башня белка (ESM-2 вектор), слияние → **скаляр-скор**
  силы связывания.
- `train_regression(X_apt, X_prot, y, cfg, seed) -> (model, stats)` — MSE по
  стандартизованному log-Kd (как two-tower Части 1); скор = −предсказанный log-Kd.
- `train_ranking(apt_feats_by_key, prot_emb, positives, cfg, seed) -> model` —
  для каждой позитивной пары (аптамер, мишень) сэмплируем K негативных мишеней
  (панели, без измеренной пары к аптамеру); попарная потеря
  `-log σ(score_pos − score_neg)` (BPR) или маржинальная; фиксированный seed,
  ранняя остановка по валидационной ранговой метрике.
- `predict_scores(model, apt_feats, prot_emb) -> np.ndarray` — скор для выровненных
  массивов (для построения профилей).

### 3. `src/run_part5.py` — оркестратор абляции 2×2

- Белковые пары → кластерный сплит → панель + известные мишени (`spectrum.py`).
- Признаки аптамера: k-меры (`aptamer.py`) и NT-эмбеддинги (`aptamer_lm.py`).
  Мишени: ESM-2 (кэш).
- Для каждой из 4 ячеек {регрессия|ранжирование} × {k-меры|NT}:
  обучить на train, построить профили test-аптамеров по панели, посчитать
  **per-aptamer ROC-AUC** (`ranking.py`) и **per-target AUC** (`per_target.py`).
- Свести в таблицу: по ячейкам — средние ROC-AUC/AUC; сравнить с baseline и с
  OLMPASS IAP (`olmpass.load_olmpass_iap`, per-target, на общих мишенях).
- Пишет `results/metrics/part5_spectrum.csv` (по ячейкам) и
  `results/metrics/part5_vs_olmpass.csv`; графики.

### Конфигурация

`configs/part5.yaml`: seed, порог кластеризации, доля теста, k, имя ESM-модели,
имя NT-модели, число негативов K на позитив, тип ранговой потери (bpr/margin),
гиперпараметры башен и обучения (скрытые размеры, dropout, lr, batch_size,
max_epochs, patience, val_fraction), гиперпараметры XGBoost-планки (при наличии).

## Поток данных

```
dataset_protein.parquet → build_pairs(keep_qualified) → cluster+split
аптамер: k-меры (aptamer.py) + NT-эмбеддинги (aptamer_lm.py)
мишень: ESM-2 (protein.py, кэш); панель + известные мишени (spectrum.py)
   └─ 2×2: ScoreTwoTower × {train_regression | train_ranking}
       └─ профили test-аптамер×панель → per-aptamer ROC-AUC + per-target AUC
   └─ сравнение ячеек ↔ baseline ↔ OLMPASS IAP → таблицы + графики
```

## Тестирование

- Юнит-тесты:
  - `embed_aptamers` — форма/детерминизм из кэша на КРОШЕЧНОЙ NT-модели (или
    мок-токенайзере, если крошечной нет);
  - `ScoreTwoTower.forward` — форма (B,); `train_regression` — переобучение
    крошечного батча (корреляция); `train_ranking` — на синтетике позитив
    получает более высокий скор, чем негатив (ранговая цель работает);
  - `predict_scores` — форма/выравнивание.
- Инвариант честности: обучение на train, профили и метрики — на test-аптамерах;
  негативы для ранжирования — только из train.
- Детерминизм при seed. Артефакты/кэши/проприетарные файлы вне git.

## Новые зависимости

Nucleotide Transformer через уже установленный `transformers` (возможно
`trust_remote_code`); при необходимости `einops`. `requirements.txt` обновляется
при фактической потребности. RDKit/новые тяжёлые — не требуются.
